# Nomadic Paws Studio three-person TestFlight checklist

Use this checklist on one consolidated build. A tester only needs to complete her own section unless a handoff explicitly involves someone else.

## Katie

- [ ] Sign in, close the app, reopen it, and unlock with the iPhone passcode without signing in again.
- [ ] Create an Adventure with multiple photos and one video from Apple Photos.
- [ ] Confirm the new media appears in the shared Media Library at full usable quality.
- [ ] Open an existing Trail Journal draft and edit its title, date, excerpt, body, category, and links.
- [ ] Confirm the future URL and GitHub filename change with the title and date.
- [ ] Add a hero image and article images, set alt text, and inspect the crop.
- [ ] Synchronize the draft and confirm the saved/synchronized language is unmistakable.
- [ ] Send the draft to CatNana and confirm it reports that it is waiting in her Today screen.
- [ ] After CatNana returns it, read every anchored note in the editor.
- [ ] Revise the requested passages, attach only the changed passages, and resend for review.
- [ ] Create or open all four Pinterest images, verify 2:3 crops and logo treatments, and inspect RSS/CSV dates.
- [ ] Open a video from Apple Photos and from the shared Media Library; preview an animated overlay and export once.
- [ ] Force-close during an unsynchronized edit, reopen, and confirm the local safety copy recovers.

## Trinitie

- [ ] Sign in, close the app, reopen it, and confirm the session is remembered.
- [ ] Confirm Today reflects the correct weekday theme.
- [ ] Open an Adventure photo from the shared Media Library.
- [ ] Confirm the one-time welcome joke restores the original immediately and never damages it.
- [ ] Draft an Instagram post with media, caption, exactly five relevant hashtags, target day, and theme.
- [ ] Save it and reopen it from Today.
- [ ] Share its preview with CatNana, then stop sharing and share it again.
- [ ] Hand the post to Katie with a note, then confirm Katie can return it without losing Trinitie’s work.
- [ ] Use Upload to Instagram and confirm the correct media and caption are available.
- [ ] Open a shared video project, edit an overlay, save it, and confirm Katie sees the same project.

## CatNana

- [ ] Sign in and confirm Today shows only Journal drafts explicitly sent for review and social previews explicitly shared by Trinitie.
- [ ] Open a Ready to review Journal card.
- [ ] Tap a paragraph and confirm it remains visually identified while the note sheet opens.
- [ ] Type or dictate a note, save it, and confirm the app clearly says it saved.
- [ ] Repeat on a second passage.
- [ ] Tap Send back to Katie and confirm the app asks whether the review is finished.
- [ ] Choose to keep reviewing once, then confirm and send it back.
- [ ] Confirm the completed story disappears from Today.
- [ ] After Katie resends revisions, confirm only changed passages appear.
- [ ] Mark one Resolved and one Still needs work, then confirm the review returns to Katie.
- [ ] Open a Trinitie-shared Instagram preview and confirm it is read-only and easy to understand.

## Shared failure checks

- [ ] Turn on Airplane Mode while editing; confirm work remains on the device and the error is calm and useful.
- [ ] Interrupt an upload; confirm Retry or recovery is obvious and the original remains safe.
- [ ] Test with the keyboard open on the smallest iPhone available; no focused field or primary action is hidden.
- [ ] Test with larger text enabled; titles and controls do not overlap.
- [ ] Confirm Register never appears in Studio navigation and Studio never requests Stripe Bluetooth or location access.
